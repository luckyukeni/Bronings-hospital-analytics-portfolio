# Power BI

- `bronings_dashboard.pbix`: the 6-page report (Executive Summary, Emergency Department, Outpatient Waiting, Capacity, Finance, Workforce). **Upload your saved .pbix here.**
- `bronings_dax_measures.dax`: all 12 required DAX measures plus the supporting ones, with expected values.
- `NHS_Bronings_theme.json`: the NHS colour theme (Design → Themes → Browse for themes).

Data source: Snowflake `BRONINGS_ANALYTICS.HOSPITAL_OPERATIONS` cleaned views, Import mode.
